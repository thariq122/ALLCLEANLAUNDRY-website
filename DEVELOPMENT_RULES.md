# Development Rules

Follow Laravel best practices.

Do not modify backend logic.

Do not rename existing routes.

Do not modify controllers unless requested.

Do not modify migrations.

Work section by section.

Finish one section before continuing.

Do not remove existing code.

Always create reusable components.

Keep CSS modular.

Separate CSS and JavaScript.

Responsive is mandatory.

Keep code clean and commented.

Ask before making major architectural changes.
